# BINA SHOR KE v4 — Audio-first Story Engine

Private Hindi short-form storytelling pipeline. Current release: `4.0.0-alpha.1`.

Start with [README_HINDI.md](README_HINDI.md). This alpha implements complete-story drafting, a separate-provider editorial gate, whole-narration Gemini TTS, human approvals, optional CPU Whisper alignment and a variable-length voice-timed storyboard. It deliberately does not include Wan/Kaggle dispatch, automated video generation or Facebook publishing.
